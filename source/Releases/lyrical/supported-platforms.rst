Lyrical 支持的平台
==================

本页面列出 ROS 2 Lyrical Luth 的目标平台和支持等级。

平台支持等级
------------

ROS 2 使用 REP 2000 定义每个发行版支持的操作系统、架构、编译器和依赖版本。Tier 1 表示最高级别的平台支持；Tier 2 和 Tier 3 表示不同程度的支持承诺。

请参阅§REP 2000：Lyrical 平台支持矩阵 <https://reps.openrobotics.org/rep-2000/>§_，查看最新的架构、操作系统版本和支持等级。

选择平台时，需要同时考虑：

* 操作系统及其版本。
* CPU 架构。
* 编译器和 C++ 标准。
* Python 版本。
* DDS/RMW 中间件实现。
* 关键第三方依赖项。

二进制软件包与源码支持
----------------------

不同平台可能提供不同形式的交付方式，包括 Debian/RPM 软件包、Windows 二进制归档包以及源码构建。并非所有 Tier 平台都会提供相同的二进制软件包。

安装前请检查 Lyrical 安装说明，并确认目标平台对应的交付方式。
