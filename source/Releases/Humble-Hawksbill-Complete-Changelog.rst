Humble Hawksbill 完整变更日志
=========================

本页面汇总 ROS 2 Humble Hawksbill 发行版相较上一发行版在 ROS 2 核心功能包中的变更。

.. contents:: 目录
   :local:

变更日志说明
------------

ROS 2 的完整变更日志按功能包组织。每个功能包条目包含版本变更、缺陷修复、新功能、依赖更新和贡献者信息。为了保留原始变更记录的准确性，功能包名称、版本号、Issue/PR 编号和贡献者名称应保持原样。

上游完整变更日志
----------------

以下内容按上游官方变更日志逐包翻译。功能包名称、版本号、Issue/PR 编号、链接和贡献者姓名保留原样；技术变更说明翻译为简体中文。

* `ROS 2 Humble 官方完整变更日志 <https://github.com/ros2/ros2_documentation/blob/humble/source/Releases/Humble-Hawksbill-Complete-Changelog.rst>`__
* `ROS 2 Humble Hawksbill 发行说明 <https://docs.ros.org/en/humble/Releases/Release-Humble-Hawksbill.html>`__

如何阅读
--------

* **功能包名称：** 点击功能包名称可打开其仓库中的 CHANGELOG 文件。
* **Issue 和 Pull Request：** 变更条目通常包含 GitHub Issue 或 PR 编号，可用于查看修改背景和讨论。
* **Contributors：** 每个功能包条目末尾列出参与该版本开发的贡献者。
* **版本比较：** 本页记录的是该发行版相较上一发行版的变更，不代表当前分支的最新状态。

.. note::

   本页翻译按功能包分批持续补充。当前已完成首批条目，后续条目仍在翻译中；在全部条目完成之前，本页不视为完整译本。
