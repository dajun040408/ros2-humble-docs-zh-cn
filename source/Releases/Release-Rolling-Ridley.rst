Rolling Ridley（``rolling``）
========================================

.. contents:: 目录
   :depth: 2
   :local:

*Rolling Ridley* 是 ROS 2 的滚动开发发行版。

.. warning::

  Rolling Ridley 会持续更新，更新可能直接覆盖现有版本，并且有时会引入破坏性变更。该发行版主要用于 ROS 2 开发，以及希望提前让自己的功能包为下一个稳定发行版做好发布准备的维护者。我们建议大多数 ROS 2 用户使用最新的 :ref:`稳定发行版 <latest-release>`。

更多信息请参阅 `REP-2002 <https://reps.openrobotics.org/rep-2002/>`_。

当前支持的平台
--------------

根据 :doc:`平台支持等级 <../The-ROS2-Project/Platform-Support-Tiers>`，Rolling Ridley 支持以下平台：

Tier 1 平台：

* Red Hat Enterprise Linux 10：``amd64``
* Ubuntu 24.04（Noble）：``amd64`` 和 ``arm64``
* Windows 11（Visual Studio 2022）：``amd64``

Tier 3 平台：

* Debian Trixie（13）：``amd64``
* Fedora Linux 44：``amd64``
* macOS：``amd64``
* OpenEmbedded / Yocto Project：``amd64``、``arm64`` 和 ``arm32``
