URDF 机器人描述
===============

URDF（Unified Robot Description Format，统一机器人描述格式）是 ROS 中用于描述机器人几何结构和组织关系的文件格式。URDF 文件采用 XML 格式，具体说明请参阅 `URDF XML 规范 <https://wiki.ros.org/urdf/XML>`_。
