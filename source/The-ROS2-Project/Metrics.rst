ROS 社区指标
============

.. contents:: 目录
   :depth: 2
   :local:

我们不会跟踪 ROS 用户个人信息，但会衡量 ROS 社区的多个方面，以了解和跟踪我们的工作所产生的影响，并识别需要改进的领域。

实时项目指标
------------

- `metrics.ros.org <https://metrics.ros.org>`_：提供 ROS 社区相关指标的可视化数据，并保持相对及时更新。
- `Linux Foundation 的 ROS LFX 仪表板 <https://insights.linuxfoundation.org/project/ros?>`_：包含最新的贡献者、开发活动、受欢迎程度和项目健康度指标。
- `OSU OSL AWStats 仪表板 <https://awstats.osuosl.org/reports/packages.ros.org/2026/01/awstats.packages.ros.org.html>`_：提供 ROS 软件包下载的实时数据。

*注意：* 要获取最新信息，需要在 AWStats URL 中指定当前的月份和年份。

- GitHub 维护了带有 `#ROS <https://github.com/topics/ros>`_ 和 `#ROS2 <https://github.com/topics/ros2>`_ 标签的软件包及项目完整列表。
- 原始 `ROS 论文 <https://scholar.google.com/scholar?cites=1227661396257612398&as_sdt=2005&sciodt=0,5&hl=en>`_（`Quigley 等，2009 <http://lars.mec.ua.pt/public/LAR%20Projects/BinPicking/2016_RodrigoSalgueiro/LIB/ROS/icraoss09-ROS.pdf>`_）和权威 `ROS 2 论文 <https://scholar.google.com/scholar?oi=bibs&hl=en&cites=1227661396257612398&as_sdt=5>`_（`Macenski 等，2022 <https://www.science.org/doi/abs/10.1126/scirobotics.abm6074>`_）的引用列表均可在 Google Scholar 中查看。

定期指标报告
------------

我们会定期发布指标报告，对 ROS 社区进行定量分析。整个社区仍在共同探索应该衡量哪些指标、如何衡量，以及如何随着系统变化不断改进。

欢迎提供反馈！如果你对如何改进这些报告有建议，请发布到 `Open Robotics Discourse 网站反馈分类 <https://discourse.openrobotics.org/c/site-feedback/3>`_。
