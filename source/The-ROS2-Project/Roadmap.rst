ROS 2 路线图
============

.. contents:: 目录
   :depth: 2
   :local:

本页面介绍 ROS 2 的计划工作。计划中的功能和开发工作有助于了解 ROS 2 的整体发展方向。如果你希望在路线图中看到其他功能，请通过 info@openrobotics.org 与我们联系。

Lyrical Luth
------------

Lyrical Luth 是预计于 2026 年 5 月发布的 ROS 2 发行版。详细时间安排请参阅 :doc:`发行版页面 <../Releases/Release-Lyrical-Luth>`。

Lyrical 路线图
--------------

正在开发的功能可在 `GitHub Project Board <https://github.com/orgs/ros2/projects/70>`_ 中跟踪。路线图中的条目代表 ROS 2 社区正在推进的主要功能。“Size（规模）”是任务预计工作量：*Small* 表示人日，*Medium* 表示人周，*Large* 表示人月。

如果你正在为 ROS 2 开发某项功能，并希望将其列入路线图，请在 `ROS 2 Documentation <https://github.com/ros2/ros2_documentation>`_ 中提交 Issue。如果你希望承担其中某项任务，请 :doc:`联系我们 <../Contact>`。

计划中的发行版
--------------

有关未来发行版的时间表和信息，请参阅 :doc:`发行版页面 <../Releases>`。

参与 ROS 2 贡献
---------------

正在寻找可以参与的工作，或希望提供帮助？以下资源可以帮助你开始：

1. :doc:`贡献指南 <Contributing>` 介绍如何为 ROS 2 做出贡献。
2. 查看 :doc:`功能创意列表 <Feature-Ideas>`，寻找灵感。
3. 有关 ROS 2 设计的更多信息，请参阅 `design.ros2.org <https://design.ros2.org>`_。
4. ROS 2 核心代码位于 `ros2 GitHub 组织 <https://github.com/ros2>`_。
5. ROS 2 设计讨论论坛位于 `Open Robotics Discourse 的 ROS 分类 <https://discourse.openrobotics.org/c/ros/111>`_。
6. 问题应发布到 `Robotics Stack Exchange <https://robotics.stackexchange.com/>`_，并至少添加 `ros2` 标签以及正在使用的 rosdistro 版本，例如 `{DISTRO}`。
