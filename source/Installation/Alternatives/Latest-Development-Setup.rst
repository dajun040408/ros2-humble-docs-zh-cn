最新开发版本（源码）
====================

如果你计划直接参与 ROS 2 最新开发版本的贡献，可以选择从源码构建 ROS 2，或安装测试版二进制软件包。这样可以获得最新的缺陷修复和功能。

测试版二进制软件包
------------------

请参阅 :doc:`测试 <../Testing>`。

从源码构建
----------

.. note::

   最新开发版本不会像正式发行版一样经过严格测试。如果你需要稳定版本的 ROS 2，不建议使用最新开发版本。建议选择已经正式发布的 :doc:`ROS 发行版 <../../Installation>`。

请根据所使用的平台，参阅以下最新配置说明：

* :doc:`Ubuntu Linux <Ubuntu-Development-Setup>`
* :doc:`macOS <macOS-Development-Setup>`
* :doc:`Windows <Windows-Development-Setup>`

如需保持源码为最新版本，请参阅 :doc:`维护源码工作空间 <../Maintaining-a-Source-Checkout>`。
