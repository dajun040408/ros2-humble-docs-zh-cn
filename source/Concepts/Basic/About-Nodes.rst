节点
====

.. contents:: 目录
   :local:

节点（Node）是 ROS 2 计算图中的参与者，它使用 :doc:`客户端库 <About-Client-Libraries>` 与其他节点通信。节点可以与同一进程内、不同进程中或另一台计算机上的节点进行通信。在 ROS 计算图中，节点通常是计算任务的基本单元；每个节点应当负责一项逻辑上独立的工作。

节点可以向命名话题 :doc:`发布 <About-Topics>` 数据，以便将数据传递给其他节点；也可以 :doc:`订阅 <About-Topics>` 命名话题，从其他节点接收数据。节点还可以作为 :doc:`服务客户端 <About-Services>`，请求另一个节点代为执行计算；也可以作为 :doc:`服务端 <About-Services>`，向其他节点提供功能。对于运行时间较长的计算任务，节点可以作为 :doc:`动作客户端 <About-Actions>`，请求另一个节点代为执行；也可以作为 :doc:`动作服务端 <About-Actions>`，向其他节点提供相应功能。节点还可以提供可配置的 :doc:`参数 <About-Parameters>`，以便在运行时改变行为。

一个节点通常是多种通信实体的复杂组合，可以同时包含发布者、订阅者、服务端、服务客户端、动作服务端和动作客户端。

节点之间的连接通过分布式 :doc:`发现机制 <About-Discovery>` 建立。

从属节点（Sub-nodes）
---------------------

在 C++（``rclcpp``）中，一个节点可以通过 ``rclcpp::Node::create_sub_node()`` 创建称为**从属节点**（subordinate nodes 或 sub-nodes）的辅助实例。从属节点与父节点共享上下文、节点接口（包括日志记录、参数、定时器和时钟）以及 ROS 计算图身份，同时可以指定额外的相对*子命名空间（sub-namespace）*。

从属节点有助于构建模块化的 C++ 软件架构。在同一节点进程中运行的内部子系统或辅助库，可以使用从属节点在限定的命名空间下发布或订阅话题和服务，而无需创建独立节点。这样可以避免额外的中间件发现开销，也无需管理多个节点的执行过程。

实际使用方法请参阅 :doc:`使用从属节点教程 </Tutorials/Intermediate/Using-Sub-Nodes>`。
