发现机制
========

.. contents:: 目录
   :local:

ROS 2 节点的发现过程由底层中间件自动完成，可概括为以下步骤：

#. 节点启动时，会向网络中具有相同 ROS 域的其他节点广播自身存在的信息。ROS 域通过 ``ROS_DOMAIN_ID``` 环境变量设置。其他节点收到广播后，会回应自身信息，以便建立适当的连接并开始通信。
#. 节点会定期广播自身状态，因此在初始发现阶段结束后，新出现的节点也能够被发现并建立连接。
#. 节点下线时，也会向其他节点通告自身状态变化。

只有在 :doc:`服务质量（QoS） <../../Tutorials/Demos/Quality-of-Service>` 设置兼容时，节点之间才会建立通信连接。

以 :ref:`talker-listener 演示 <talker-listener>` 为例：在一个终端中运行 C++ talker 节点，它会向某个话题发布消息；在另一个终端中运行 Python listener 节点，它会订阅同一个话题。

你会看到这两个节点自动发现彼此，并开始交换消息。
