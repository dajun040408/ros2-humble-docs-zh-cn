启动系统（Launch）
==================

.. contents:: 目录
   :local:

ROS 2 系统通常由许多节点组成，这些节点可能运行在不同进程中，甚至分布在不同计算机上。虽然可以手动启动每个节点，但随着节点数量增加，这种方式很快就会变得繁琐。

ROS 2 的启动系统（Launch）用于通过一条命令自动启动多个节点。它帮助用户描述系统配置，并按照配置执行启动流程。系统配置包括：要运行哪些程序、程序运行位置、需要传递哪些参数，以及如何通过不同配置复用系统组件。启动系统还负责监控已启动进程的状态，并报告或响应进程状态变化。

上述配置都写在“启动文件（launch file）”中。启动文件可以使用 XML、YAML 或 Python 编写，然后通过 ``ros2 launch`` 命令运行，启动文件中指定的节点都会被启动。

要开始编写和使用启动文件，请参阅 `启动系统教程 <../../Tutorials/Intermediate/Launch/Launch-Main>`_。

更多详细信息请参阅 `launch 文档 <https://docs.ros.org/en/{DISTRO}/p/launch>`__。
